\section{Numerical implementation}
The background system is integrated with adaptive Runge--Kutta methods and dense-output event localization at $H=0$. Physical-domain exits are root-localized and preserved as rejected outcomes rather than silently discarded. The Friedmann constraint is monitored through the normalized residual
\begin{equation}
\epsilon_F=\frac{H^2+k/a^2-\rho_{\rm tot}/(3\Mpl^2)}{\max(|\rho_{\rm tot}/(3\Mpl^2)|,\epsilon_*)}.
\end{equation}
In the reduced-Planck-unit implementation $\Mpl=1$. Turning states are taken from the adaptive solver's continuous interpolant, not from the plotting grid. Every result records configuration and output hashes, solver settings, dependency information, and platform metadata. Publication results require a tolerance ladder, an independent-integrator cross-check, and a predeclared maximum residual \cite{wilkinson2016,barker2022}.

\subsection{Independent turning-point physics audit}
A root reported at $H=0$ is not accepted merely because an event callback fired. For every serialized exact event state $(a_\star,H_\star,\phi_\star,\dot\phi_\star)$ the analysis independently recomputes $V$, all component densities and pressures, the $H=0$ Friedmann surface residual, $\rho+p$, $\rho+3p$, and two algebraically independent forms of the local Hubble derivative,
\begin{align}
\dot H_\star^{(R)}&=\frac{k}{a_\star^2}-\frac12\left(\rho_m+\frac43\rho_r+\dot\phi_\star^2\right),\\
\dot H_\star^{(T)}&=-\frac16(\rho_\star+3p_\star).
\end{align}
It also evaluates the exact turning margin
\begin{equation}
\Delta_\star=V(\phi_\star)-\frac12\rho_m(a_\star)-\rho_r(a_\star)-\dot\phi_\star^2,
\end{equation}
so that $\Delta_\star>0$ predicts a bounce and $\Delta_\star<0$ a turnaround. The recorded event kind is compared against this independently reconstructed theorem classification. The diagnostic is serialized with the background result. Agreement authenticates the local event evidence; it does not imply recurrence or stability.

\subsection{Sparse-redshift distance correction}
For a comparison expansion function $E(z)=H(z)/H_0$, the line-of-sight comoving distance is
\begin{equation}
D_C(z)=\frac{c}{H_0}\int_0^z\frac{dz'}{E(z')}.
\end{equation}
An earlier implementation used a cumulative trapezoid on the requested redshift array and therefore assigned zero distance to its first element. That is valid only when the first element is exactly $z=0$ and the grid is sufficiently dense; a sparse BAO vector begins at positive redshift. The corrected implementation anchors every integral at the physical lower limit $z=0$ and uses adaptive quadrature at each unique requested redshift. It is regression-tested against the exact Einstein--de Sitter result
\begin{equation}
D_C(z)=\frac{2c}{H_0}\left(1-\frac{1}{\sqrt{1+z}}\right).
\end{equation}
Expansion functions whose density parameters fail the $z=0$ closure relation are rejected rather than silently renormalized.

\subsection{Verification protocol}
The stored background-verification run compares DOP853 at coarse, medium, and reference tolerances and separately compares DOP853 with RK45 on the same output grid. For a stored state component $y$, the normalized comparison error is
\begin{equation}
\epsilon_y=\frac{\lVert y-y_{\rm ref}\rVert_\infty}{\max(\lVert y_{\rm ref}\rVert_\infty,\epsilon_{\rm floor})}.
\end{equation}
The acceptance thresholds are $|\epsilon_F|_{\max}<10^{-7}$, medium-to-reference error below $10^{-5}$, and independent-solver error below $10^{-5}$. Solver verification compares the unwrapped scalar trajectory: periodicity of $V$ does not erase a physical field displacement on the declared real target space.

For a stronger Stage~1 recurrence-candidate gate, global trajectory agreement is necessary but not sufficient. The candidate protocol therefore compares the complete root-localized event topology: event count, ordered bounce/turnaround sequence, normalized event times, exact event states, completion status, and physical-domain termination kind. It requires at least two same-kind return metrics, hence at least three exact turning points of that kind, below the declared return threshold in every verification run. The close returns must reproduce under a tighter DOP853 tolerance ladder and under the algorithmically distinct implicit Radau solver. A candidate is promoted only if these event checks, the full unwrapped trajectory, the Friedmann residual, and the independent turning-point physics audit all pass simultaneously.

This candidate audit is intentionally non-promotional. If the reference background has insufficient or nonclosing repeated returns, the output is a machine-readable negative result rather than a numerical failure. Stage~2 Poincare/Floquet analysis remains blocked until a Stage~1 background actually passes this gate.
