\section{Numerical validation}
\label{app:numerical-validation}

The test suite includes the Einstein--de Sitter expansion law, monotonic luminosity distance, an exact flat de Sitter scalar-field limit, potential-derivative verification, compact-phase return metrics, and manifest-schema validation.

The background verification workflow executes a declared tolerance ladder and an independent-integrator comparison. For a stored state component $y$, the reported normalized error is
\begin{equation}
  \epsilon_y = \frac{\lVert y-y_{\mathrm{ref}}\rVert_\infty}
  {\max(\lVert y_{\mathrm{ref}}\rVert_\infty,\epsilon_{\mathrm{floor}})}.
\end{equation}
The stratification field is compared modulo its potential period, preventing equivalent compact-phase representatives from being counted as a large discrepancy. The verification report records componentwise errors, the maximum Friedmann-constraint residual, configuration hashes, solver methods, tolerances, and predeclared acceptance thresholds.

Repeated turning points are assessed by comparing consecutive states of the same event class. Their state vectors are taken directly from the adaptive solver's root-localized event output and serialized separately from the uniformly sampled plotting trajectory. Consequently, return metrics do not depend on the requested output-sampling density. The return metric includes the relative scale-factor mismatch, wrapped phase mismatch, and relative field-velocity mismatch. A sufficiently small and converged return error is labelled only as a recurrent background candidate; it is not a proof of a stable limit cycle. Poincar\'e maps, variational equations, Floquet multipliers, perturbation-stability analysis, and synthetic parameter recovery remain required later-stage tests.
