\section{Numerical validation}
\label{app:numerical-validation}

The test suite includes the Einstein--de Sitter expansion law, a sparse positive-redshift
Einstein--de Sitter distance regression, monotonic luminosity distance, positive-definite DESI
covariance validation, an exact flat de Sitter scalar-field limit, potential-derivative
verification, topology-aware return metrics, and manifest-schema validation. The sparse-redshift
test is specifically designed to prevent the first DESI distance from being assigned zero merely
because the requested measurement grid begins above $z=0$.

The background verification workflow executes a declared tolerance ladder and an
independent-integrator comparison. For a stored state component $y$, the reported normalized error
is
\begin{equation}
  \epsilon_y = \frac{\lVert y-y_{\mathrm{ref}}\rVert_\infty}
  {\max(\lVert y_{\mathrm{ref}}\rVert_\infty,\epsilon_{\mathrm{floor}})}.
\end{equation}
Solver verification always compares the unwrapped scalar trajectory. A displacement by one or
more periods of the potential is therefore retained, because a periodic potential alone does not
identify the scalar target space. This prevents distinct separatrix crossings or winding histories
from being hidden by a modulo comparison. The verification report records componentwise errors,
the maximum Friedmann-constraint residual, configuration hashes, solver methods, tolerances, and
predeclared acceptance thresholds.

The DESI inference workflow has a separate validation hierarchy. The small Gaussian likelihood
files are checksum-pinned. The local CAMB maximum-posterior optimizer is a deterministic regression
check only; posterior contours are constructed from the official DESI MCMC chain release. Chain
files remain external and their URLs, sizes, and SHA-256 hashes are written into each generated
inference report. CAMB supplies the drag horizon and high-redshift species densities. A legacy
Aubourg approximation is evaluated only as a supplementary backend cross-check.

Repeated turning points are assessed by comparing consecutive states of the same event class.
Their state vectors are taken directly from the adaptive solver's root-localized event output and
serialized separately from the uniformly sampled plotting trajectory. Consequently, return
metrics do not depend on the requested output-sampling density. For the baseline real scalar, the
full field displacement is retained and normalized by the adjacent-minimum spacing of the
potential. A circular target space must be declared explicitly; adjacent minima remain distinct,
while a return after one full target circumference is recorded as a nonzero-winding return. Return
counts and error summaries are evaluated independently for bounces and turnarounds. Even repeated
close returns in one integration are not a proof of recurrence or a stable limit cycle.
Reproduction across tolerances and independent solvers, Poincar\'e maps, variational equations,
Floquet multipliers, perturbation-stability analysis, and synthetic parameter recovery remain
required later-stage tests.
