\section{Reproducibility and data availability}
\label{app:reproducibility}

The source repository contains the simulation code, configurations, tests, manuscript sources, and a release manifest. External data remain in their authoritative archives. Each result release will provide software and configuration identifiers, external-product versions and checksums, labeled numerical arrays, diagnostics, and scripts sufficient to regenerate all figures and tables. This organization follows FAIR principles for data and research software \citep{wilkinson2016fair,barker2022fair4rs}.
