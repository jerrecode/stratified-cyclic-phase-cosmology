\section{Reproducibility and data availability}
\label{app:reproducibility}

The repository contains the simulation code, configurations, tests, manuscript sources, and release manifests. External data remain in their authoritative archives. Every result release should provide the software commit, configuration hashes, dependency versions, external-product identifiers and checksums, labeled numerical arrays, diagnostics, and commands sufficient to regenerate all reported figures and tables. Large raw maps and catalogs are not manuscript dependencies unless their exact archive selection and transformation workflow is recorded.
